## Development Guidelines

- Keep changes small and focused — one feature or fix per commit.
- Write clear, descriptive commit messages explaining *why* a change was made.
- Test any code changes before committing.

## Git Workflow

- The default branch is `main`.
- Create feature branches for new work (e.g., `claude/feature-name`).
- Push changes and open pull requests for review before merging to `main`.
