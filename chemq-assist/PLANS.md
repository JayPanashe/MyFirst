# PLANS.md
## Purpose
Use execution plans for complex ChemQ Assist tasks that require multiple steps, multiple files, research plus code, or a decision gate.

## When to create a plan
Create or update a plan when the task involves:
- a new module;
- an MVP milestone;
- external API integration;
- data model design;
- partner search;
- opportunity scoring;
- AlphaFold workflows;
- quantum chemistry workflows;
- report generation;
- outreach deliverables.

## Plan format
Each plan should include:
1. Objective
2. Current context
3. Assumptions
4. Files to create or modify
5. Step-by-step implementation tasks
6. Tests/checks
7. Risks and limitations
8. Definition of done
9. Next task

## Execution rule
Do not jump directly into implementation for complex work.
First create or update the relevant plan in `backlog/`, then implement against that plan.

## Research rule
For research-heavy tasks, include:
- source list;
- evidence quality notes;
- uncertainty notes;
- claims that need verification;
- suggested partner or expert validation.
