# chemq-assist

ChemQ Assist is a Codex-ready software + research repository for chemistry, structural biology, and opportunity intelligence workflows.

## Quick start

```bash
uv sync
uv run pytest
```

## Structure overview

- `docs/`: concept, strategy, methods, and outreach notes.
- `data/`: raw, interim, processed, and external data layers.
- `notebooks/`: exploratory notebooks and API exploration scaffolds.
- `src/chemq/`: reusable application package code.
- `tests/`: verification for config and scoring logic.
- `outputs/`: generated reports, tables, and figures.
- `prompts/`: reusable prompt assets.
- `backlog/`: sprint task documents.
